# 🔢 JavaScript Number Operations Program

## Objective

The objective of this project is to create a JavaScript program that performs multiple operations on a given number. The program uses different variables, loops, and conditional statements to demonstrate core JavaScript concepts and displays results using `console.log()`.

---

## Operations Performed

This program performs the following operations:

1. **Sum of First N Numbers**
   Calculates the sum from 1 to N.

2. **Multiplication Table**
   Prints the multiplication table of the given number up to 10.

3. **Prime Number Check**
   Determines whether the number is prime or not.

4. **Factors of the Number**
   Displays all factors of the given number.

5. **Sum of Digits**
   Calculates the sum of all digits in the number.

6. **Armstrong Number Check**
   Checks whether the number is an Armstrong number (e.g., 153).

##  Code Overview

The program uses:

* **Loops** (`for`, `while`) for calculations
* **Conditional statements** (`if-else`) for decision making
* **Operators** (`%`, `+`, `**`) for mathematical operations
* **Math functions** (`Math.floor`)

Each operation uses **separate variables** to maintain clarity and avoid conflicts.
