# Interactive Greeting Webpage

## Objective

This project demonstrates basic DOM manipulation using HTML, CSS, and JavaScript.

## Features

- Header displays "Hello" initially.
- Four clickable boxes:
  - Red
  - Blue
  - Green
  - Yellow
- Input field for user name.
- Greeting button.
- Clicking the button changes the heading to:

```
Hello, YourName
```

- Clicking a box changes its background color to the respective color.

## Files

- index.html
- style.css
- script.js
- README.md

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM)

## How to Run

1. Download the project.
2. Open `index.html` in any web browser.
3. Enter your name.
4. Click **Greet Me**.
5. Click any color box to fill it with the respective color.

## Output

- Greeting changes dynamically.
- Boxes change color when clicked.
