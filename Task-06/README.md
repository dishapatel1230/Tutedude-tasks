# Flexbox Login Page
This project is a simple login page created using HTML and CSS.  
The layout is built using Flexbox to keep the login form centered on the screen.  
It includes input fields for username and password and a login button.

## What I Learned
From this project I learned how Flexbox helps in aligning elements easily.  
Using `display: flex`Using `display: flex` made it simple to center the login box.  
`display:flex` makes a container use Flexbox layout so its child elements can be aligned and arranged easily.
`flex: 1` means the element will take available space equally inside the flex container.  
I also learned the difference between `justify-content` and `align-items` for positioning elements.This centers content both horizontally and vertically.
I also understood how `100vh` helps in vertically centering the layout.

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Run the `index.html` file in any browser.


## Challenge I Faced
At first I had difficulty centering the login form vertically on the page.  
After learning about `height: 100vh` and using Flexbox with `align-items: center`, I was able to solve the problem.
