# Hero Section Animation

## 📌 Description
This project enhances the hero section by adding an animated image.

The image moves in an orbit path and changes its shape slightly to create a more dynamic visual effect.

## 🎯 Features
- Smooth orbit rotation
- Elliptical motion effect
- Squeeze/stretch animation

## 🛠️ Technologies Used
- HTML
- CSS

## ▶️ How to Run
1. Open the project folder
2. Run index.html in a browser

## 📁 Files
- index.html
- style.css
- image.png

## 💡 Explanation
- `translate` is used to create orbit motion
- `scale()` is used to create squeeze/stretch effect
