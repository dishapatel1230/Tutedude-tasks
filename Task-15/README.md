# JavaScript Array Operations

This project demonstrates basic array operations in JavaScript using different types of functions such as arrow functions, anonymous functions, and traditional functions.

# Features

The program performs the following operations on an array:

 Find the maximum number in the array
 Calculate the sum of all elements
 Count the number of odd numbers

# Program Overview
    Arrow Functions (=>)
    Anonymous Functions
    Traditional Functions
    Array Iteration (for...of, forEach)
    Conditional Statements
    
##  Technologies Used

* JavaScript (Vanilla JS)
* Browser Console

##  How to Run the Project

1. Open the project folder in **VS Code**
2. Install **Live Server Extension**
3. Right-click on `index.html`
4. Click **"Open with Live Server"**
5. Open browser console (**F12 → Console**)
6. View the results

## Sample Output
Array: [10, 25, 7, 42, 19, 8, 33]
Maximum number: 42
Sum of elements: 144
Count of odd numbers: 4
