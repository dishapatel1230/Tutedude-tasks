
## Javascript: Map() & Filter()
The objective of this project is to create a web page that displays student records using HTML, CSS, and JavaScript.

The project also includes a search feature to filter students by name using JavaScript functions like `map()` and `filter()`.

---
## JavaScript Concepts Used
## map()
map() is used to loop through the student array
It creates HTML cards for each student
It helps render data dynamically on the page
## filter()
filter() is used for searching students
It checks whether the entered name matches student data
It returns only matching student records
---

##  Features
- Display student records in card format
- Search students by name
- Dynamic rendering using JavaScript
- Real-time filtering of student data
- Beginner-friendly implementation

---

##  Technologies Used

* JavaScript (Vanilla JS)
* Browser Console

##  How to Run the Project

1. Open the project folder in **VS Code**
2. Install **Live Server Extension**
3. Right-click on `index.html`
4. Click **"Open with Live Server"**
5. Open browser console (**F12 → Console**)
6. View the results
