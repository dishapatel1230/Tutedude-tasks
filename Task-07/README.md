# Laundry Service Hero Section – Task 7

This project is a responsive hero section for a laundry service website.
It was created using **HTML and CSS** as part of **Task 7** in the Tutedude MERN Stack Web Development course.

In this task, I improved the previous layout by making the hero section **fully responsive for desktop, tablet, and mobile screens** using **Flexbox and media queries**.

---

## Features

* Navigation bar with:

  * Home
  * Services
  * About Us
  * Contact Us
* Logo displayed on the left side
* Username shown on the right side
* Hero section with:

  * Heading
  * Description
  * "Book a service today" button
  * Laundry service image
* Responsive layout for different screen sizes

---

## Technologies Used

* HTML
* CSS

Concepts practiced in this task:

* Flexbox layout
* Media queries
* Responsive design
* CSS box model
* Viewport units

---

## Responsive Design

The layout adapts to different screen sizes.

Desktop:

* Text on the left
* Image on the right

Tablet:

* Layout adjusts spacing and image size

Mobile:

* Content stacks vertically
* Image appears below the text

## Challenges I Faced

One challenge was making the hero section look good on smaller screens.
At first the layout broke when the screen size decreased.

I fixed this by using **Flexbox and media queries** to change the layout for tablet and mobile views.
